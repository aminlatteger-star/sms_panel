# پنل اطلاع‌رسانی پیامکی به والدین

پنل ساده‌ی تحت‌وب برای ثبت دانش‌آموزان (نام + شماره والد) و ارسال پیامک با یک عنوان دلخواه.

این پروژه رو می‌تونی به دو روش اجرا کنی:
- **محلی روی سیستم خودت** (برای تست) — با Node.js ساده
- **آنلاین روی Cloudflare Pages** (توصیه‌شده) — رایگان، همیشگی، و چون روی شبکه‌ی
  کلادفلره معمولاً بدون فیلترشکن هم در دسترسه

## اجزای پروژه
- `server.js`, `db.js`, `sms.js` — نسخه‌ی اجرای محلی (Node.js ساده، بدون وابستگی خارجی)
- `functions/` — نسخه‌ی Cloudflare Pages Functions (همون منطق، برای اجرا روی کلادفلر)
- `public/` — رابط کاربری (HTML/CSS/JS) — بین هر دو نسخه مشترکه
- `schema.sql` — دستورات ساخت جدول‌های دیتابیس (برای Cloudflare D1)

## اجرا روی سیستم خودت (تست)
1. نصب Node.js نسخه‌ی 22 یا بالاتر از nodejs.org
2. داخل پوشه‌ی پروژه: `node server.js`
3. مرورگر: `http://localhost:3000`

## آنلاین کردن پنل روی Cloudflare (رایگان، بدون خط فرمان)

با این روش فقط با **۲ سرویس** کار داری: **GitHub** (نگه‌داری کد) و **Cloudflare**
(هم اجرای سرور، هم دیتابیس، هم CDN — همه یه‌جا). چون کلادفلر شبکه‌ی خیلی گسترده‌ای
داره، معمولاً بدون فیلترشکن هم در دسترسه.

### قدم ۱ — آپلود کد به گیت‌هاب
1. برو به github.com و یه اکانت رایگان بساز (اگه از قبل نداری).
2. دکمه‌ی `+` بالا سمت راست → **New repository** → یه اسم بده → **Create repository**.
3. تو صفحه‌ی ریپازیتوری، لینک **uploading an existing file** رو بزن.
4. فایل‌های zip رو اول **Extract/استخراج** کن، بعد همه‌ی فایل‌ها و پوشه‌ها
   (`public`, `functions`, `schema.sql`, و بقیه) رو بکش و بنداز تو همون صفحه.
5. **Commit changes** رو بزن.

### قدم ۲ — ساخت دیتابیس D1 در Cloudflare
1. برو به dash.cloudflare.com و یه اکانت رایگان بساز (یا با گیت‌هابت وارد شو).
2. از منوی سمت چپ برو **Workers & Pages** → تب **D1 SQL Database** → **Create Database**.
3. یه اسم بده (مثلاً `smspanel`) → **Create**.
4. وارد همون دیتابیس شو → تب **Console**.
5. محتوای فایل `schema.sql` (که تو zip هست) رو کامل کپی کن، تو کادر Console پیست کن،
   و دکمه‌ی اجرا (**Execute** یا **Run**) رو بزن. این کار جدول‌ها رو می‌سازه.

### قدم ۳ — ساخت پروژه‌ی Pages و وصل کردن به دیتابیس
1. از همون منوی **Workers & Pages**، تب **Pages** رو باز کن → **Create** → **Connect to Git**.
2. ریپازیتوری‌ای که تو قدم ۱ ساختی رو انتخاب کن و **Begin setup** بزن.
3. تنظیمات build:
   - **Framework preset**: None
   - **Build command**: خالی بذار
   - **Build output directory**: `public`
4. دکمه‌ی **Save and Deploy** رو بزن (اولین دیپلوی هنوز دیتابیس وصل نیست، طبیعیه).
5. بعد از تموم شدن، برو به **Settings** همون پروژه‌ی Pages → بخش **Functions** →
   **D1 database bindings** → **Add binding**:
   - **Variable name**: دقیقاً بنویس `DB` (با همین حروف بزرگ، چون کد دقیقاً همینو می‌خونه)
   - **D1 database**: همون `smspanel` که ساختی رو انتخاب کن
6. یه بار دیگه از تب **Deployments**، آخرین دیپلوی رو **Retry deployment** کن (یا یه
   تغییر کوچیک تو گیت‌هاب بده) تا دیتابیس واقعاً وصل بشه.
7. لینک نهایی بالای صفحه‌ست، چیزی شبیه: `https://smspanel.pages.dev`

از این به بعد، پنل ۲۴ ساعته آنلاینه، هیچ‌وقت نمی‌خوابه، لیست دانش‌آموزا و تاریخچه
تو دیتابیس D1 (که مال خودته) ذخیره میشه، و بدون خط فرمان یا فیلترشکن کار می‌کنه.

## راه‌اندازی درگاه پیامک (رایگان، از طریق گوشی خودت)
این پنل پیامک رو مستقیم نمی‌فرسته؛ به یه اپلیکیشن روی گوشی اندرویدت وصل میشه که پیامک واقعی رو
از طریق سیم‌کارت خودت ارسال می‌کنه. پروژه‌ی پیشنهادی و رایگان: **android-sms-gateway**
(https://github.com/capcom6/android-sms-gateway)

مراحل:
1. اپ رو از لینک گیت‌هاب بالا (بخش Releases) روی گوشی اندرویدت نصب کن.
2. اپ رو باز کن و اجازه‌ی ارسال پیامک بده؛ یه آدرس، یوزرنیم و پسورد بهت نشون میده.
3. وارد پنل شو → منوی همبرگری → «تنظیمات پیامک» → همون‌ها رو وارد کن و ذخیره کن.
4. گوشی باید همیشه روشن، به اینترنت وصل و اپ در پس‌زمینه فعال باشه.

نکته: چون پنل الان روی اینترنت (Cloudflare) اجرا میشه و گوشیت تو خونه‌ست، باید طبق
مستندات همون اپ از حالت **Cloud/Relay** (که خودشون رایگان ارائه میدن) استفاده کنی،
نه وصل شدن مستقیم به IP گوشی — چون IP خونه از بیرون معمولاً در دسترس نیست.

## نکات امنیتی
این پنل هیچ سیستم ورود/رمز عبور نداره — یعنی هر کسی که لینکش رو داشته باشه می‌تونه ازش استفاده
کنه. اگه می‌خوای فقط خودت بهش دسترسی داشته باشی، بگو تا یه صفحه‌ی ورود با رمز عبور هم اضافه کنم.
